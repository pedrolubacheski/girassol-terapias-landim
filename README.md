# 🌻 Espaço Girassol - Terapias

Uma landing page moderna, responsiva e elegante desenvolvida para o **Espaço Girassol**, um centro dedicado a terapias corporais e bem-estar. O projeto apresenta informações sobre serviços oferecidos (como Terapia Craniossacral e Liberação Miofascial), benefícios das terapias, história profissional e um canal de contato integrado.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando o ecossistema moderno do ecossistema front-end:

* **React** (Vite) - Biblioteca para construção da interface de usuário em componentes reaproveitáveis.
* **Tailwind CSS** - Framework CSS utilitário para estilização rápida e design totalmente responsivo.
* **JavaScript (ES6+)** - Lógica e manipulação de estados do ecossistema React.
* **HTML5 & CSS3** - Estruturação e ajustes globais de estilização.

---

## 📱 Recursos e Funcionalidades

* **Design Totalmente Responsivo:** Interface otimizada e fluida para dispositivos móveis, tablets e computadores.
* **Menu Hambúrguer Fluido:** Navegação prática e adaptada para telas menores que se auto-fecha ao clicar.
* **Navegação por Âncoras (Smooth Scroll):** Rolagem suave ao navegar pelas seções do site através do cabeçalho.
* **Seções Detalhadas:**
    * **Hero / Home:** Boas-vindas institucionais impactantes.
    * **Benefícios:** Apresentação das vantagens do cuidado com a saúde e o sistema nervoso.
    * **Sobre Mim:** Espaço dedicado à jornada e autoridade do terapeuta.
    * **Serviços:** Vitrine das terapias aplicadas no consultório.
    * **Contato / Rodapé:** Informações de acesso rápido para agendamentos.

---

## 🛠️ Como Executar o Projeto Localmente
